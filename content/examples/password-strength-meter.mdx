A signup password field with a live strength bar — no submit required, updates on every keystroke.

## Markup

```html
<form id="signupForm">
  <input type="password" name="password" id="passwordField">
  <div id="strengthBar"><div id="strengthFill"></div></div>
  <span id="strengthLabel"></span>
  <p id="strengthSuggestions"></p>
</form>
```

## Script

```js
import NFSFU234FormValidation from 'nfsfu234-form-validation';

const form = new NFSFU234FormValidation({ form: 'signupForm' });

const passwordField = document.getElementById('passwordField');
const fillEl = document.getElementById('strengthFill');
const labelEl = document.getElementById('strengthLabel');
const suggestionsEl = document.getElementById('strengthSuggestions');

passwordField.addEventListener('input', () => {
  const { score, label, suggestions } = form.passwordStrength(passwordField.value);

  fillEl.style.width = `${score}%`;
  labelEl.textContent = label;
  suggestionsEl.textContent = suggestions.join(' ');
});
```

## Notes

- `passwordStrength()` is synchronous — no `await`, no network call. It's cheap enough to run on every `input` event.
- `label` is one of `'very weak' | 'weak' | 'fair' | 'good' | 'strong'`, `score` is `0`–`100`, and `suggestions` is an array of plain-language tips ("add a number", etc.) you can join or render as a list.
- This is a UX signal only, not a security guarantee — it doesn't check the password against breach lists or enforce anything server-side. Pair it with `checkPassword()` (or your own server-side rules) if you need to actually reject weak passwords, rather than just nudge the user.
