Hey developers! 🎉 We're excited to introduce the NFSFU234FormValidation Browser Extension (Alpha) — bringing form validation testing and previewing right to your browser, no code required.

## Key features

- **Seamless integration** — works directly with the library, no setup.
- **Comprehensive validation options** — global or on-demand.
- **Customization** — define your own rules and themes.

## Getting started

The extension is alpha and not yet on the Chrome/Firefox stores. Grab the latest build from the [Releases page](https://github.com/NFSFU234FormValidation/nfsfu234formvalidation-web-extension/releases) and follow the README for manual installation.

## Modes of operation

- **Global validation** — runs automatically across every form you visit.
- **On-demand validation** — toggle it from the extension popup when you need it.
