Hello there! 👋 We're thrilled to introduce you to NFSFU234FormValidation — a lightweight JavaScript library that makes form validation a breeze, whether you're working with plain HTML forms or React.

## Why you'll love it

- **Customizable validation messages** — tailor errors to your product's voice.
- **Required field support** — make sure the important stuff gets filled in.
- **Inline error displays** — messages appear right where the user needs them.
- **Modal error notifications** — for a more deliberate, focused error flow.

## Getting started

Check out the [Installation guide](/docs/v3/installation) to get the library into your project, then head to [Initialization](/docs/v3/initialization) to wire it up.

## Basic example

```js
const customErrorMessages = {
  text: "EMPTY FIELD",
  select: "SELECT FIELD IS REQUIRED",
  email: {
    empty: "EMPTY EMAIL",
    format: "The email is not in the right format"
  }
};

const myForm = document.getElementById("myForm");
nfsfu234FormValidation.validate(myForm, { customErrorMessages }, (response) => {
  const { message, type, data } = response;
  console.log(response);
});
```
