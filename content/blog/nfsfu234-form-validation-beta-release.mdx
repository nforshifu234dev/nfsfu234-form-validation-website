Hey there, amazing developers! 👋 We're thrilled to announce NFSFU234FormValidation v3 (Beta) — a major update to make form validation smoother and more powerful than ever.

## What's new

- **Framework compatibility** — first-class support for React and Vite alongside plain HTML.
- **TypeScript rewrite** — the core moved from vanilla JS to TypeScript for better reliability and DX.
- **Improved error handling** — new `ErrorMessage` and `ErrorHandler` interfaces give clearer, more structured error data.
- **Revamped methods** — `submit()` and `validate()` now return a Promise resolving to an [ErrorMessageInterface](/docs/v3/errorMessageInterface).

**Naming note:** as part of the move to stable, the `js-required` class and `jsSubmit` id are being renamed to `nfsfu234-fv-required` and `nfsfu234-fv-form` respectively, for a cleaner, more consistent naming convention.

For the full picture, see the [Changelog](/docs/v3/changelog) or browse [all available functions](/docs/v3/available-functions).
