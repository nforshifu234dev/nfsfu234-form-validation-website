# 🔒 Security Policy

Thank you for helping keep **NFSFU234FormValidation** and its documentation ecosystem secure.

We take security seriously and appreciate responsible disclosure of potential vulnerabilities.

---

## 🚨 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately by contacting the project maintainer with:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected version(s)
* Any proof-of-concept or screenshots (if applicable)
* Suggested mitigations (optional)

Providing as much information as possible helps us investigate and resolve issues more quickly.

[NFORSHIFU234Dev Contact Page](https://www.nforshifu234dev.com/contact)

---

## ⚡ What to Expect

After receiving a report, we aim to:

* 📩 Acknowledge receipt within **72 hours**
* 🔍 Investigate the issue promptly
* 🤝 Work with the reporter throughout the disclosure process
* 🛠️ Release a fix as quickly as reasonably possible
* 🙏 Credit the reporter (with permission)

Response times may vary depending on the complexity and severity of the issue.

---

## 🛡️ Supported Versions

Please report vulnerabilities affecting supported versions of the project.

Refer to **SUPPORTED_VERSIONS.md** for the current maintenance policy.

---

## ❤️ Responsible Disclosure

We kindly ask that you:

* Give us reasonable time to investigate and resolve the issue before public disclosure.
* Avoid accessing, modifying, or deleting data that does not belong to you.
* Avoid disrupting the availability of our services.
* Act in good faith to help improve the security of the project.

We appreciate researchers who follow responsible disclosure practices.

---

## 📜 Scope

This policy applies to:

* The NFSFU234FormValidation documentation website
* Documentation generation scripts
* Supporting infrastructure contained within this repository

Security issues affecting the **NFSFU234FormValidation** library itself should also be reported through the same responsible disclosure process.
