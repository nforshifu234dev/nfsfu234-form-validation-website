# validateAllTextarea

The `validateAllTextarea` function validates all textarea inputs within a specified form. It returns an array of error messages (a nested [ErrorMessageInterface](/docs/v2/errorMessageInterface)) or a single instance of [ErrorMessageInterface](/docs/v2/errorMessageInterface) if all fields are valid..

**Works in:** HTML5, React JS

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `form` | `HTMLFormElement \| HTMLDivElement \| string` | `undefined` | The form element or its ID containing textarea inputs. |
| `options` | `object` | `{}` | Optional settings for validation such as custom error messages. |

## Usage

### Example: Validate All Textarea Inputs in a Form

```js
const formElement = document.getElementById('myForm');
const result = nfsfu234FormValidation.validateAllTextarea(formElement, {
  message: 'Please provide valid input in all textareas.'
});
console.log(result);
```
