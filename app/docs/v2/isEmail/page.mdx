# isEmail

The `isEmail` function is used to validate whether a given string is a valid email address.

**Works in:** HTML5, React JS, Node.js

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `email` | `string` | `undefined` | The string to validate as an email address. |

## Usage

### Example: Validate Email

```js
const email = 'example@example.com';
const isValidEmail = nfsfu234FormValidation.isEmail(email);
console.log(isValidEmail); // true
```

### Another Example: Validate Email

```js
const email = 'example@example';
const isValidEmail = nfsfu234FormValidation.isEmail(email);
console.log(isValidEmail); // false
```
