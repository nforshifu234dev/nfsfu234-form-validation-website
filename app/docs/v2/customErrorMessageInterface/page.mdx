# CustomMessagesInterface

The `CustomMessagesInterface` defines the structure of custom error messages for various input types in the NFSFU234FormValidation Library. These custom messages allow developers to specify user-friendly error messages for different types of input fields during form validation.

| `checkbox` | `string` | `undefined` | Custom error message for checkbox inputs. |
| `color` | `string` | `undefined` | Custom error message for color inputs. |
| `datetime` | `string` | `undefined` | Custom error message for datetime inputs. |

| `datetime-local` | `string` | `undefined` | Custom error message for datetime-local inputs. |

## Usage

### Example: Setting Custom Error Messages using the [`Validate API`](/docs/v2/validate) function

```js
const customMessages = {
  email: {
    empty: "Please enter your email address.",
    invalid: "The email address you entered is not valid."
  },
  password: "Your password must be at least 8 characters long."
};

nfsfu234FormValidation.validate(myForm, { customErrorMessages: customMessages }, (response) => {
  if (!response.isValid) {
    console.log(response.errorMessages);
  }
});
```
