#### togglePasswordVisibility
Toggles a single password field between masked and visible, swapping
an optional show/hide icon accordingly.
**Returns:** `any`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `input` | `HTMLInputElement` | `required` | `-` | The password input to toggle. |
| `showIcon` | `null \\| string \\| HTMLElement` | `optional` | `null` | The icon element (or its CSS id) to display when the password is hidden. |
| `hideIcon` | `null \\| string \\| HTMLElement` | `optional` | `null` | The icon element (or its CSS id) to display when the password is visible. |

##### Usage

###### Example: Toggle Password Visibility

```js
const passwordInputField = document.querySelector("input[type=password]");
const showIcon = '🙈';
const hideIcon = '👀';

nfsfu234FormValidation.togglePasswordVisibility(passwordInputField, showIcon, hideIcon);
```
