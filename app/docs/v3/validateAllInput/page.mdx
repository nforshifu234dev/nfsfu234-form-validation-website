#### validateAllInput
Validates every input in the form. Returns `true`, or an array of
per-field error results.
**Returns:** `boolean \| ErrorMessageInterface[]`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `string \\| HTMLFormElement \\| HTMLDivElement` | `required` | `-` | The form to validate, as an element or its CSS id. Defaults to this instance's `form` if omitted. |
| `customErrorMessages` | `any` | `required` | `-` | Custom error messages keyed by field name or rule, overriding the defaults. |

##### Usage

###### Example: Validate All Input Fields in a Form

```js
const formElement = document.getElementById('myForm');

nfsfu234FormValidation.validateAllInput(formElement, {
  customErrorMessages: {
    email: 'Please enter a valid email address.',
    url: 'Please enter a valid URL.',
    date: 'Please enter a valid date.',
  }
}).then(response => {
  console.log(response);
});
```
