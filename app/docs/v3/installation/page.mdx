# Installation

NFSFU234FormValidation works in plain HTML, React, Next.js, Vue, Vite, Astro, and any project that runs JavaScript in the browser.

Choose your preferred package manager below.

<Tabs items={["npm", "pnpm", "Yarn", "Bun", "CDN"]}>

<Tabs.Tab>

```bash
npm install @nfsfu234/form-validation
```

</Tabs.Tab>

<Tabs.Tab>

```bash
pnpm add @nfsfu234/form-validation
```

</Tabs.Tab>

<Tabs.Tab>

```bash
yarn add @nfsfu234/form-validation
```

</Tabs.Tab>

<Tabs.Tab>

```bash
bun add @nfsfu234/form-validation
```

</Tabs.Tab>

<Tabs.Tab>

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@nfsfu234/form-validation/dist/css/nfsfu234FormValidation.min.css"
/>

<script src="https://cdn.jsdelivr.net/npm/@nfsfu234/form-validation/dist/js/nfsfu234FormValidation.js"></script>
```

</Tabs.Tab>

</Tabs>

---

## Importing CSS

When using a package manager, import the bundled stylesheet once.

```javascript
import "@nfsfu234/form-validation/css";
```
