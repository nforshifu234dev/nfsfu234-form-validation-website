## 🛠️ Installation

You can install the NFSFU234FormValidation Library via CDN, npm, or yarn.

<Tabs items={['CDN', 'npm', 'yarn']}>
  <Tabs.Tab>
    Paste this into the `<head>` of your HTML5 document:

```html
    <script src="https://cdn.jsdelivr.net/npm/nfsfu234-form-validation@latest/dist/js/nfsfu234FormValidation.js"></script>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nfsfu234-form-validation@latest/dist/css/nfsfu234FormValidation.min.css" />
```
  </Tabs.Tab>
  <Tabs.Tab>
    For npm-based projects (React, Vue, etc.):

```bash
    npm install nfsfu234-form-validation
```
  </Tabs.Tab>
  <Tabs.Tab>
    For yarn-based projects:

```bash
    yarn add nfsfu234-form-validation
```
  </Tabs.Tab>
</Tabs>

Pick whichever method fits your project. Next, head to [Initialization](/docs/v3/initialization) to wire the library up.
