#### validateAllCheckbox
Validates every checkbox in the form.
**Returns:** `boolean \| ErrorMessageInterface \| ErrorMessageInterface[]`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `HTMLFormElement \\| HTMLDivElement` | `required` | `-` | The form to validate. Defaults to this instance's `form` if omitted. |
| `options` | `any` | `required` | `-` | Custom error messages / overrides keyed by field name. |

##### Usage

###### Example: Validate All Checkboxes in a Form

```js
const formElement = document.getElementById('myForm');
const result = validateAllCheckbox(formElement, {
  message: 'You must check all required checkboxes.'
});
console.log(result);
```
