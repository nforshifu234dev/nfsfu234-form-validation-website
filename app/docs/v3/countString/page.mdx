#### countString
Counts the number of characters in a string.
**Returns:** `number`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `string` | `string` | `required` | `-` | The string to measure. |

##### Usage

###### Example: Count Characters in a String

```js
const text = 'Hello World';
const characterCount = nfsfu234FormValidation.countString(text);
console.log(characterCount); // 11
```
