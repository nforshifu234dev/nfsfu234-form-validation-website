## Using NFSFU234FormValidation with Create React App

### 1. Create a CRA project

```bash
npx create-react-app my-app
cd my-app
```

### 2. Install the library

```bash
npm install nfsfu234-form-validation
```

### 3. Wire it up in a function component

```jsx
import { useEffect } from 'react'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function SignupForm() {
  useEffect(() => {
    const formElement = document.getElementById('signup-form')
    const validator = new NFSFU234FormValidation({ form: formElement })

    async function handleSubmit(e) {
      e.preventDefault()
      const result = await validator.submit()
      console.log(result)
    }

    formElement.addEventListener('submit', handleSubmit)
    return () => formElement.removeEventListener('submit', handleSubmit)
  }, [])

  return (
    <form id="signup-form">
      <input type="email" name="email" required />
      <input type="password" name="password" minLength="8" required />
      <button type="submit">Sign up</button>
    </form>
  )
}
```

### 4. Or in a class component

Older CRA codebases still lean on class components — the equivalent setup uses `componentDidMount`/`componentWillUnmount` instead of `useEffect`:

```jsx
import { Component } from 'react'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

class SignupForm extends Component {
  componentDidMount() {
    this.formElement = document.getElementById('signup-form')
    this.validator = new NFSFU234FormValidation({ form: this.formElement })
    this.handleSubmit = async (e) => {
      e.preventDefault()
      const result = await this.validator.submit()
      console.log(result)
    }
    this.formElement.addEventListener('submit', this.handleSubmit)
  }

  componentWillUnmount() {
    this.formElement.removeEventListener('submit', this.handleSubmit)
  }

  render() {
    return (
      <form id="signup-form">
        <input type="email" name="email" required />
        <input type="password" name="password" minLength="8" required />
        <button type="submit">Sign up</button>
      </form>
    )
  }
}

export default SignupForm
```

### 5. Or use the site-wide config registry

```jsx
import { useEffect } from 'react'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function FormsInit() {
  useEffect(() => {
    NFSFU234FormValidation.configureForms([
      {
        form: '#signup-form',
        fields: {
          email: { required: true, type: 'email' },
          password: { required: true, minLength: 8 }
        }
      }
    ])
    NFSFU234FormValidation.autoInit()
  }, [])

  return null
}
```

### 6. Common gotcha: don't call it at module scope

CRA's dev server is quick to surface `document is not defined`-style errors if any validator call ends up outside a lifecycle method — always inside `componentDidMount`/`useEffect`, never in `render()` or at the top of the file.
