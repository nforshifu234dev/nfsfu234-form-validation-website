# Frameworks

NFSFU234FormValidation is dependency-free and works anywhere a real DOM exists. Pick your setup below for a from-scratch walkthrough — installation, wiring a form up, and the one gotcha specific to that environment.

| Framework | Best for |
| --- | --- |
| [Next.js](/docs/v3/frameworks/nextjs) | App Router or Pages Router projects — client component setup, SSR gotcha |
| [Vite](/docs/v3/frameworks/vite) | Vite + React projects — no SSR to worry about, StrictMode double-invoke note |
| [Create React App](/docs/v3/frameworks/cra) | CRA projects, function or class components |
| [Expo (Web)](/docs/v3/frameworks/expo) | Expo projects targeting web — `Platform.OS` guarding required |
| [Plain HTML](/docs/v3/frameworks/html) | No build step, no bundler — a single script tag |

All five guides end with the same next steps: the [`FormConfigInterface`](/docs/v3/formConfigInterface) reference for multi-form setups, [`validateFile`](/docs/v3/validateFile) for file/image uploads, and the full [available functions](/docs/v3/available-functions) list.

Looking for working demos instead of setup guides — multi-step forms, AJAX submission, file preview? Check out [Examples](/examples).
