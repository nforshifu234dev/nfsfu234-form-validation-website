## Using NFSFU234FormValidation with Expo (Web)

NFSFU234FormValidation reads and manipulates real DOM elements, so it only works on Expo's **web** target — there's no DOM on iOS or Android. Every example below is guarded with a `Platform.OS === 'web'` check for that reason.

### 1. Create an Expo project

```bash
npx create-expo-app my-app
cd my-app
```

### 2. Install the library

```bash
npm install nfsfu234-form-validation
```

It's pure JS with no native modules, so a plain `npm install` is enough — no `expo install` or config plugin needed.

### 3. Wire it up on a web-only screen

```jsx
import { useEffect } from 'react'
import { Platform, View, Text } from 'react-native'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function SignupScreen() {
  useEffect(() => {
    if (Platform.OS !== 'web') return

    const formElement = document.getElementById('signup-form')
    const validator = new NFSFU234FormValidation({ form: formElement })

    async function handleSubmit(e) {
      e.preventDefault()
      const result = await validator.submit()
      console.log(result)
    }

    formElement.addEventListener('submit', handleSubmit)
    return () => formElement.removeEventListener('submit', handleSubmit)
  }, [])

  if (Platform.OS !== 'web') {
    return (
      <View>
        <Text>Sign-up is available on the web version of this app.</Text>
      </View>
    )
  }

  // On web, react-native-web renders <View>/<Text> as real DOM elements,
  // but for a form with native HTML semantics (required, minLength, submit
  // events) it's simplest to drop into raw HTML tags here.
  return (
    <form id="signup-form">
      <input type="email" name="email" required />
      <input type="password" name="password" minLength="8" required />
      <button type="submit">Sign up</button>
    </form>
  )
}
```

### 4. Or use the site-wide config registry

Same guard applies:

```jsx
import { useEffect } from 'react'
import { Platform } from 'react-native'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function FormsInit() {
  useEffect(() => {
    if (Platform.OS !== 'web') return

    NFSFU234FormValidation.configureForms([
      {
        form: '#signup-form',
        fields: {
          email: { required: true, type: 'email' },
          password: { required: true, minLength: 8 }
        }
      }
    ])
    NFSFU234FormValidation.autoInit()
  }, [])

  return null
}
```

### 5. Common gotcha: it silently no-ops on native, but other calls won't

The constructor itself checks `typeof window === 'undefined'` and just sets `form` to `undefined` rather than throwing — so building `new NFSFU234FormValidation()` on iOS/Android won't crash. But calling instance methods like `.validateInput()` or `.submit()` on native *will* throw, since those reach for `document` directly. Always gate the whole flow behind `Platform.OS === 'web'`, not just the constructor call.
