## ▲ Using NFSFU234FormValidation with Next.js

This guide walks through a fresh Next.js project end to end — no prior setup assumed.

### 1. Create a Next.js project

```bash
npx create-next-app@latest my-app
cd my-app
```

Pick whichever options you like for the App Router prompt — this guide works with either App Router or Pages Router.

### 2. Install the library

```bash
npm install nfsfu234-form-validation
```

### 3. Import it in a Client Component

The library reads and manipulates the DOM directly, so it needs to run in the browser — mark the component `'use client'`.

```jsx
'use client'

import { useEffect } from 'react'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function SignupForm() {
  useEffect(() => {
    const formElement = document.getElementById('signup-form')
    const validator = new NFSFU234FormValidation({ form: formElement })

    async function handleSubmit(e) {
      e.preventDefault()
      const result = await validator.submit()
      console.log(result)
    }

    formElement.addEventListener('submit', handleSubmit)
    return () => formElement.removeEventListener('submit', handleSubmit)
  }, [])

  return (
    <form id="signup-form">
      <input type="email" name="email" required />
      <input type="password" name="password" minLength="8" required />
      <button type="submit">Sign up</button>
    </form>
  )
}
```

### 4. Or use the site-wide config registry

For multiple forms across pages, `configureForms()` + `autoInit()` is usually cleaner than wiring each form by hand:

```jsx
'use client'

import { useEffect } from 'react'
import NFSFU234FormValidation from 'nfsfu234-form-validation'

export default function FormsInit() {
  useEffect(() => {
    NFSFU234FormValidation.configureForms([
      {
        form: '#signup-form',
        fields: {
          email: { required: true, type: 'email' },
          password: { required: true, minLength: 8 }
        }
      }
    ])
    NFSFU234FormValidation.autoInit()
  }, [])

  return null
}
```
Mount `<FormsInit />` once in your root layout — `autoInit()` only wires up whichever registered form is actually present on the current page.

### 5. Common gotcha: SSR

Don't call any validator function at the top level of a Server Component or during render — the library expects `window`/`document` to exist. Always call it inside `useEffect()` (client-side, post-mount) as shown above.
