# 🏎️ Getting Started

NFSFU234FormValidation is a lightweight, dependency-free client-side validation library. It reads the `required`, `pattern`, `minlength`, and `type` attributes already on your form — no config needed for the common cases.

## Install

```bash
npm install nfsfu234-form-validation
```

Or via CDN, no build step required:

```html
<script src="https://cdn.jsdelivr.net/npm/nfsfu234-form-validation/dist/js/nfsfu234FormValidation.global.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nfsfu234-form-validation/dist/css/nfsfu234FormValidation.min.css">
```

## Quick start

Given a form with standard HTML validation attributes:

```html
<form id="loginForm">
  <input type="email" name="email" required>
  <input type="password" name="password" required minlength="8">
  <button type="submit">Log in</button>
</form>
```

Attach the library and call `.submit()`:

```js
import NFSFU234FormValidation from 'nfsfu234-form-validation';

const form = new NFSFU234FormValidation({ form: 'loginForm' });

document.getElementById('loginForm').addEventListener('submit', () => {
  form.submit().then((result) => {
    if (result.type === 'success') {
      // validated (and submitted via AJAX, if configured)
    }
  });
});
```

That's it — `email` gets checked as a real email address, `password` is checked against `minlength="8"`, and both are checked for `required`. Nothing else to configure.
