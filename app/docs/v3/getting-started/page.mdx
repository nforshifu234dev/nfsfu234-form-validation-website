# 🏎️ Getting Started

Welcome to **NFSFU234FormValidation**.

NFSFU234FormValidation is a lightweight, dependency-free client-side form validation library for modern JavaScript applications.

Instead of replacing the browser's native validation, it builds on top of it. If your forms already use HTML validation attributes like `required`, `type`, `pattern`, `minlength`, or `maxlength`, you're already halfway there.

Version 3 extends those familiar HTML capabilities with configuration-driven validation, framework-friendly APIs, automatic form initialization, file validation, AJAX utilities, and much more.

## What is NFSFU234FormValidation?

NFSFU234FormValidation helps you build better forms without forcing you to rewrite how HTML forms already work.

Instead of inventing a completely new validation syntax, the library understands the HTML validation attributes browsers already support while adding functionality modern applications commonly need.

That means you can continue writing standard HTML like this:

```html
<input
    type="email"
    required
    minlength="5"
/>
```

…and Version 3 can extend that with features such as:

- Configuration-driven validation rules
- Site-wide form registration
- Automatic multi-page initialization
- File and image validation
- Custom validation messages
- Static AJAX requests
- Password utilities
- TypeScript support
- Zero runtime dependencies

## What Gets Validated Automatically?

Without writing any configuration, the library understands standard HTML validation rules.

| HTML Attribute | Automatically Validated |
| -------------- | ----------------------- |
| `required` | ✅ |
| `type="email"` | ✅ |
| `type="url"` | ✅ |
| `pattern` | ✅ |
| `minlength` | ✅ |
| `maxlength` | ✅ |
| `min` | ✅ |
| `max` | ✅ |
| `step` | ✅ |
| Required radio groups | ✅ |
| Required checkboxes | ✅ |
| Select elements | ✅ |
| Textareas | ✅ |

For many projects, that's enough to get started.

When you need additional control, Version 3 allows you to override or extend HTML validation using JavaScript configuration instead of changing your markup.

## What's New in Version 3?

Version 3 is the largest update since the project began.

Highlights include:

- 🚀 Configuration-driven validation
- 🌍 Site-wide form registry with `configureForms()`
- ⚡ Automatic page initialization using `autoInit()`
- 📁 File and image validation
- 🔄 Promise-based `.validate()` and `.submit()`
- 🌐 Static AJAX helper
- 📦 Scoped npm package: `@nfsfu234/form-validation`
- 🧪 Complete automated test suite
- 📚 API documentation generated with TypeDoc
- ⚛️ Improved React, Next.js and SSR support
- 📦 Zero runtime dependencies
