#### validateAllTextarea
Validates every ``<textarea>`` field in the form.
**Returns:** `boolean \| ErrorMessageInterface \| ErrorMessageInterface[]`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `HTMLFormElement \\| HTMLDivElement` | `required` | `-` | The form to validate. |
| `options` | `any` | `required` | `-` | Custom error messages / overrides keyed by field name. |

##### Usage

###### Example: Validate All Textarea Inputs in a Form

```js
const formElement = document.getElementById('myForm');
const result = nfsfu234FormValidation.validateAllTextarea(formElement, {
  message: 'Please provide valid input in all textareas.'
});
console.log(result);
```
