#### validateTextarea
Validates a single ``<textarea>`` field.
**Returns:** `string \| boolean \| ErrorMessageInterface`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `textareaField` | `HTMLTextAreaElement` | `required` | `-` | The textarea to validate. |
| `options` | `any` | `required` | `-` | Overrides for the field's validation rule (e.g. `required`, `minLength`, `maxLength`). |

##### Usage

###### Example: Validate a Textarea Input

```js
// Using with a textarea input element
const textareaElement = document.querySelector('textarea');
const result = nfsfu234FormValidation.validateTextarea(textareaElement, {
  message: 'Please provide a valid input.'
});
console.log(result);
```
