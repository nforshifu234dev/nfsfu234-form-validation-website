# Available Functions

Every public method and static function, grouped by category. Click through to any function for full parameter details and usage examples.

### Static Methods

| Function | Type | Description |
| --- | --- | --- |
| [`autoInit()`](/docs/v3/autoInit) | Static | Scans the current page for whichever registered forms are present and wires each one up (novalidate, submit handling, and AJAX submission if configured). Call this once per page, after configureForms() has been called with the site's full form config. |
| [`configureForms(configs)`](/docs/v3/configureForms) | Static | Register form configs for the whole site in one place - typically a single shared config file included on every page. Only forms actually present in the current page's DOM get wired up when autoInit() runs, so it's safe to register every form on the site. |

### Core

| Function | Type | Description |
| --- | --- | --- |
| [`submit(userOptions?, callback?)`](/docs/v3/submit) | Instance | Validates the whole form (every input, textarea, select, radio, checkbox, and file field), then—if validation succeeds and AJAX is enabled—submits the form using either the supplied AJAX options or the instance's default AJAX configuration.  The method first resolves the target form from the supplied `userOptions` (or falls back to the form attached to this instance), validates it, and finally submits it if appropriate.  Validation-only usage is also supported. When AJAX is not enabled, the method simply resolves with the validation result. |
| [`validate(userOptions?, callback?)`](/docs/v3/validate) | Instance | Validates the whole form (every input, textarea, select, radio, checkbox, and file field) without submitting it. |
