#### reset
Resets all fields in a form to their default/empty values.
**Returns:** `boolean`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `u_form` | `string \\| HTMLFormElement \\| HTMLDivElement` | `required` | `-` | The form to reset, as an element or its CSS id. Defaults to this instance's `form` if omitted. |

##### Usage

###### Example: Reset Form Elements

```js
const formId = "myForm";
nfsfu234FormValidation.reset(formId); // Resets the form with ID 'myForm'

const formElement = document.getElementById('myForm');
nfsfu234FormValidation.reset(formElement); // Resets the form element directly
```
