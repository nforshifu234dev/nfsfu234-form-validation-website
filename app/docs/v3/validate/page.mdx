#### validate
Validates the whole form (every input, textarea, select, radio,
checkbox, and file field) without submitting it. Always async;
always returns a `Promise`.
**Returns:** `Promise<any>`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `userOptions` | `string \\| HTMLFormElement \\| HTMLDivElement \\| object` | `optional` | `-` | Overrides the form/customErrorMessages set at construction. |
| `callback` | `any` | `optional` | `-` | Optional callback invoked with the result instead of/alongside the returned Promise. |

##### Usage

###### Option 1.

```js
const myForm = document.getElementById("myForm")
nfsfu234FormValidation.validate(form)
.then((response) => {
    const { message, type, data } = response;
    console.log(response);
});
```

###### Option 2.

```js
const myForm = document.getElementById("myForm");
nfsfu234FormValidation.validate(myForm, (response) => {
    const { message, type, data } = response;
    console.log(response);
});
```
