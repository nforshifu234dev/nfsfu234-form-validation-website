#### validateFile

The `validateFile` function validates a single `<input type="file">` field: required/min/max file count, accepted file types, max size per file, and — for image files — min/max width and height. It's the library's only **async** field validator, since checking image dimensions requires decoding the file first.

**Works in:** HTML5, React

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `fileInputField` | HTMLInputElement | — | The file input field to validate. |
| `options` | object | `{}` | Validation options — `form`, `errorType`, `customErrorMessages`. |

New in v3. Rules are mostly config-driven via [`configureForms()`](/docs/v3/available-functions), since there's no HTML attribute equivalent for file size or image dimension limits.

##### Configuring a file field

```js
NFSFU234FormValidation.configureForms([
  {
    form: '#profileForm',
    fields: {
      avatar: {
        required: false,
        accept: ['image/png', 'image/jpeg'],
        maxSizeMB: 2,
        maxWidth: 1000,
        maxHeight: 1000,
        message: 'Avatar must be PNG or JPEG, under 2MB, and no larger than 1000×1000px.'
      }
    }
  }
]);
```

If a field has no config entry, `accept` falls back to the field's native HTML `accept="..."` attribute, and `required` falls back to the native `required` attribute — the same override pattern used by every other field validator in the library.

##### `accept` shorthand

Alongside exact MIME types (`'image/png'`), wildcards (`'image/*'`), and extensions (`'.pdf'`), `accept` also understands friendly category shorthand:

| Shorthand | Matches |
| --- | --- |
| `'image'` | any `image/*` MIME type |
| `'video'` | any `video/*` MIME type |
| `'audio'` | any `audio/*` MIME type |
| `'document'` | `.pdf`, `.doc`, `.docx`, `.odt`, `.txt`, `.rtf` |

##### Usage

###### Example: Validate a file input

```js
const fileElement = document.querySelector('input[type="file"]');
const result = await nfsfu234FormValidation.validateFile(fileElement, { form: myForm });
console.log(result);
```
