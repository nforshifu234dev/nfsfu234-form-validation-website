#### validateFile
Validates a single ``<input type="file">`` field: required/min/max file
count, accepted types (`accept`), max size (`maxSizeMB`), and - for
images - dimension limits. Async, since checking image dimensions
requires decoding the file.
**Returns:** `Promise<boolean \| ErrorMessageInterface>`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `fileInputField` | `HTMLInputElement` | `required` | `-` | The file input to validate. |
| `options` | `any` | `optional` | `-` | File rule overrides: `required`, `accept`, `maxSizeMB`, `minFiles`, `maxFiles`, `maxWidth`, `maxHeight`, `minWidth`, `minHeight`, and their `*Message` variants. |

##### Usage

###### Example: Validate a file input

```js
const fileElement = document.querySelector('input[type="file"]');
const result = await nfsfu234FormValidation.validateFile(fileElement, { form: myForm });
console.log(result);
```
