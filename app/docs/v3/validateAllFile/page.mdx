#### validateAllFile
Validates every ``<input type="file">`` field in the form. Async - see
validateFile.
**Returns:** `Promise<boolean \| ErrorMessageInterface[]>`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `form` | `HTMLFormElement \\| HTMLDivElement` | `required` | `-` | The form to validate. Defaults to this instance's `form` if omitted. |
| `options` | `any` | `optional` | `-` | File rule overrides, applied across all file fields unless a field specifies its own. |

##### Usage

###### Example: Validate every file field in a form

```js
const result = await nfsfu234FormValidation.validateAllFile(myForm);

if (result === true) {
  // every file field passed
} else {
  // result is an array of ErrorMessageInterface
  console.log(result);
}
```
