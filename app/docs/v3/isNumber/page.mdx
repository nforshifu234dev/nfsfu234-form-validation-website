#### isNumber

The `isNumber` function checks if the given value is a number.

**Works in:** HTML5, React, nodejs

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `number` | `string \| number` | `undefined` | The value to check. |

##### Usage

###### Example: Check if Value is a Number

```
const value = 123;
const isValidNumber = nfsfu234FormValidation.isNumber(value);
console.log(isValidNumber); // true
```

###### Example: Check if Value is a Number

```
const value = "123";
const isValidNumber = nfsfu234FormValidation.isNumber(value);
console.log(isValidNumber); // true
```
