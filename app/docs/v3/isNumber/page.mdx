#### isNumber
Checks whether a value is numeric.
**Returns:** `boolean`
| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `number` | `string \\| number` | `required` | `-` | The value to check, as a string or number. |

##### Usage

###### Example: Check if Value is a Number

```js
const value = 123;
const isValidNumber = nfsfu234FormValidation.isNumber(value);
console.log(isValidNumber); // true
```
