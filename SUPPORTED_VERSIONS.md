# 📦 Supported Versions

This document describes the maintenance policy for the **NFSFU234FormValidation Official Documentation Website** and the documentation it hosts.

---

## Current Support Policy

| Version  |     Status    | Support                                                            |
| :------- | :-----------: | :----------------------------------------------------------------- |
| **v3.x** |    ✅ Active   | New features, bug fixes, documentation updates, and security fixes |
| **v2.x** |   🟡 Legacy   | Critical documentation fixes only                                  |
| **v1.x** | ❌ End of Life | No longer maintained                                               |

---

## Documentation Versions

The website currently hosts multiple versions of the documentation to help developers migrate between releases.

### v3

* Actively maintained
* Receives new documentation
* Receives new examples
* Receives API updates
* Receives migration guides

---

### v2

The v2 documentation remains available for developers maintaining existing projects.

Only critical corrections (such as broken links or major documentation errors) may be applied.

No new features or examples will be added.

---

### v1

The original documentation is no longer maintained.

Developers are encouraged to migrate to **v3** using the migration guides available on the official documentation website.

---

## Security Updates

Security-related documentation updates will only be published for supported versions.

---

## Versioning Policy

This project follows **Semantic Versioning (SemVer)**.

Major releases may introduce new documentation structures, navigation, or developer experience improvements while preserving previous documentation whenever practical.
